NAIA API 설정

NovelAI 영구 토큰 발급 가이드

NAIA에서 NovelAI를 사용하려면 NovelAI 계정의 영구 API 토큰이 필요합니다. 아래 순서대로 토큰을 복사한 뒤 NAIA의 API 설정 창에 붙여넣고 저장하세요.

NovelAI 이미지 페이지 열기 NAIA로 돌아가기
주의 영구 토큰은 비밀번호처럼 취급하세요. 다른 사람에게 보내거나 공개된 채팅, 문서, 화면 공유에 노출하지 않는 것이 안전합니다.
1

NovelAI 이미지 페이지에서 메뉴를 엽니다

NovelAI 이미지 페이지에 로그인한 뒤, 오른쪽 위의 메뉴 버튼을 누릅니다.

2

계정 설정으로 이동합니다

사용자 메뉴가 열리면 Account Settings 항목을 선택합니다.

3

영구 API 토큰 발급 창을 엽니다

계정 화면의 아래쪽에서 Get Persistent API Token 버튼을 누릅니다. 현재 구독 등급이 표시되는 계정 화면에서 찾을 수 있습니다.

4

토큰을 복사합니다

토큰 창이 열리면 복사 버튼을 누릅니다. 토큰 전체를 직접 펼쳐 볼 필요는 없습니다.

5

NAIA에 붙여넣고 저장합니다

NAIA의 API 설정 창으로 돌아와 영구 토큰 입력칸에 붙여넣고 확인 후 저장을 누릅니다.

저장에 성공하면 NAIA가 토큰을 보관하고 NovelAI 연결 상태를 갱신합니다. 저장 후에는 입력칸에 토큰 원문이 계속 표시되지 않습니다.

이 문서는 NAIA 로컬 서버에서 제공됩니다. 화면 예시는 토큰 발급 위치를 안내하기 위한 참고 이미지입니다.

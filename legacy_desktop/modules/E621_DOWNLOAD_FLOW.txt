코드 흐름 요약:
==============

1. create_widget()
   ├─ if not data_path.exists():
   │   └─ _create_download_ui() → return widget
   └─ else: 정상 UI 생성

2. _create_download_ui()
   ├─ 중앙 정렬 컨테이너 생성
   ├─ 제목/설명 레이블 추가
   ├─ 다운로드 버튼 생성
   │   └─ clicked.connect(_on_download_clicked)
   └─ 진행 상태 레이블 생성

3. _on_download_clicked()
   ├─ 버튼 비활성화
   ├─ E621DataDownloadWorker(URL, target_path) 생성
   ├─ progress_updated.connect(_on_download_progress)
   ├─ download_finished.connect(_on_download_finished)
   └─ worker.start()

4. E621DataDownloadWorker.run() [백그라운드]
   ├─ urllib.request.urlopen() 호출
   ├─ while loop: 8KB 블록 단위 다운로드
   │   ├─ progress_updated.emit() 실시간 발송
   │   └─ total_size 기반 퍼센트 계산
   └─ download_finished.emit() 완료 시그널

5. _on_download_finished(success, message)
   ├─ if success:
   │   ├─ QMessageBox.information() 안내
   │   └─ "모듈 재시작 필요" 메시지
   └─ else:
       ├─ QMessageBox.warning() 오류
       └─ 버튼 재활성화

6. 모듈 재시작 (사용자 수동)
   └─ create_widget() 재호출 → 정상 UI 표시


주요 시그널 흐름:
================

E621DataDownloadWorker (QThread)
  │
  ├─ progress_updated(percent, message)
  │   └─→ _on_download_progress()
  │        ├─ progress_label.setText(message)
  │        └─ download_btn.setText(f"다운로드 중... {percent}%")
  │
  └─ download_finished(success, message)
      └─→ _on_download_finished()
           ├─ if success: QMessageBox.information()
           └─ else: QMessageBox.warning()


예외 처리:
==========

try:
    urllib.request.urlopen(...)
    ...다운로드 로직...
except urllib.error.HTTPError as e:
    → "HTTP 오류 {code}: {reason}"
except urllib.error.URLError as e:
    → "네트워크 오류: {reason}"
except Exception as e:
    → "오류: {str(e)}"

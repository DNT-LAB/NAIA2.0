번호가 여러 개 붙은 메뉴(프롬프트 도구 · NAI 전용 도구)는 안에 여러 그룹의 기능이 섞여 있다는 뜻입니다. 각 항목은 해당 그룹의 표에 나눠 적었습니다.

④ 스타일그림체(작가)를 정하거나 스타일을 탐색합니다.

Chunk

Studio

Auto Gen

Automation

결과 그림을 선화·스케치·채색·표정 바꾸기·배경 지우기로 변형합니다. 배경 지우기는 Anlas가 많이 듭니다.

Upscale · Enhance

결과 그림을 2배로 키우거나(Upscale) 살짝 다시 그려 다듬습니다(Enhance). Anlas가 듭니다.

Char Ref

참조 그림의 캐릭터나 화풍을 닮게 그립니다. 장당 5 Anlas가 듭니다.

Vibe Transfer

참조 그림의 색감·화풍·분위기를 생성에 입힙니다. 새 그림 인코딩은 2 Anlas가 듭니다.

레퍼런스 인셋

참조 그림을 캔버스 한쪽에 두고 남은 칸에 닮은 캐릭터를 그립니다(큰 캔버스는 Anlas).

결과 우클릭 › NAI 도구

결과 그림을 업스케일·img2img·인페인트·Char Ref·Vibe로 바로 넘깁니다.

Inpaint 설정

인페인트 그림을 1MP로 줄여 Anlas를 아낄지, 원본 크기를 지킬지 정합니다.

Metadata

그림에 담긴 프롬프트와 설정을 읽어서 내 화면에 그대로 다시 적용합니다.

Generation Info

고른 결과에 실제로 들어간 프롬프트를 보고, 태그를 눌러 뜻을 확인합니다.

History · Open Folder

지난 결과를 다시 열어 보고, 저장 폴더를 탐색기로 엽니다. 히스토리의 아이템을 우클릭 하면 다양한 기능이 제공됩니다.

Auto Save

생성한 그림을 폴더에 자동으로 저장할지 정하고, 저장 안 된 그림은 한 번에 저장합니다.

결과 우클릭 메뉴

결과 그림의 프롬프트·설정을 불러오거나 큐 추가·복사·삭제를 바로 합니다.

히스토리 브라우저

지난 결과를 큰 화면에서 넘겨 보고 확대·삭제·일괄 정리합니다. 개편 예정입니다. 불편함.

히스토리 줄 설정

삭제할 때 저장 파일까지 지울지, 확인을 물을지 정하고 저장 경로를 봅니다.
